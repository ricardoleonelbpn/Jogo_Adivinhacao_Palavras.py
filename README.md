# 🎯 Jogo de Adivinhação de Palavras

Um projeto desenvolvido em **Python** com o objetivo de praticar lógica de programação, estruturas de repetição, condicionais e manipulação de strings.

## 📖 Sobre o projeto

O jogador deve descobrir uma palavra secreta escolhida aleatoriamente pelo programa.

A cada tentativa, o sistema fornece dicas para ajudar na próxima jogada.

## 🚀 Funcionalidades

* Escolha aleatória da palavra secreta.
* Validação da quantidade de letras digitadas.
* Contagem do número de tentativas.
* Possibilidade de jogar novamente.
* Sistema de dicas semelhante ao Wordle:

| Dica  | Significado                                         |
| ----- | --------------------------------------------------- |
| **A** | Letra correta na posição correta                    |
| **a** | Letra existe na palavra, mas está na posição errada |
| **_** | Letra não existe na palavra                         |

## 🛠️ Tecnologias utilizadas
